# Viva Preparation

Each member should be able to explain:

1. Why NodeGoat satisfies the component and Docker requirements.
2. The browser → Express → MongoDB data flow and trust boundaries.
3. Why `eval()` and MongoDB `$where` turn data into executable logic.
4. How the IDOR is prevented by using the session identity.
5. How SSRF occurs and why a fixed destination reduces the attack surface.
6. Why password hashing needs a salt and a password KDF.
7. What each GitHub Actions security gate detects.
8. Which gate is configured to fail and what severity threshold applies.
9. How secrets reach Docker and CI without being committed.
10. What evidence was actually executed by the group and what limitations remain.

Do not memorise unexplained answers. Be prepared to open the relevant source file and demonstrate the control.
