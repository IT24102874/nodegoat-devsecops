# AI Usage Disclosure Guidance

The assignment explicitly permits AI assistance when it is honestly disclosed. This project package was prepared with AI-assisted planning, source review, secure coding suggestions, pipeline configuration and documentation drafting.

Before submission, the group must replace this general description with the exact tool names used by each member and the actual purpose of that usage. The group remains responsible for testing, validating, understanding and defending all submitted work.

No AI-generated screenshot, scanner result, pipeline run or other execution evidence should be presented as genuine unless a group member actually produced it.
